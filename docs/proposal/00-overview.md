# 交易研究系統總覽

## 專案名稱

**Cyclical Alpha Research System (CARS)** — 景氣循環股超額報酬研究系統

## 系統願景

從一位在航運股上獲得巨額回報的投資人的方法論中提煉出可複製、可量化的交易研究框架，使其能系統性地套用於不同景氣循環產業（記憶體、AI 供應鏈、面板、航運、原物料等），在獲利爆發初期識別被嚴重低估的標的，並以歷史回測數據作為估值的客觀依據。

## 核心方法論萃取

該投資人的方法論可歸納為以下六大支柱：

### 1. 產業景氣指標追蹤（情報系統）
- 追蹤產業領先指標（如航運的 SCFI 指數）
- 掌握供需失衡的結構性因素（缺櫃、塞港、產能週期）
- 監控淡旺季節奏與運價/報價趨勢

### 2. 本業 EPS 估算框架
- 區分本業 vs. 業外獲利，過濾一次性收益灌水
- 使用公式：`本業EPS = 實際EPS × (營業利益率 × (1-稅率) / 稅後淨利率)`
- 按季度建立悲觀/中立/樂觀三種情境估算

### 3. 歷史本益比回測（20 年台股全市場）
- 回測台股 20 年所有股票的「本業本益比」
- 發現關鍵規律：本業獲利 + 正常配息(5成以上) → 本益比至少 6 倍
- 本業 EPS > 15 元的高獲利股 → 本益比幾乎至少 9 倍
- 此規律跨越牛熊市（含 2008 金融海嘯）、跨越所有產業

### 4. 估值方法論：P/E 優於 P/B
- 以統計數據證明：市場資金追逐獲利爆發股時，本益比區間穩定（9~20x），淨值比區間極度發散（0.98~10.55x）
- 結論：P/B 是果（事後除出來的數字），P/E 才是因（市場資金追逐的依據）
- P/B 的用途僅限於判斷股價下限（清算價值），P/E 用於判斷股價上限

### 5. 情境分析與目標價計算
- 目標價 = 本業 EPS 估值 × 歷史回測支持的最低本益比倍數
- 動態調整：隨運價/報價、季報、配息政策、資本結構事件即時更新
- 考量因素：虧損抵扣額回沖、現金增資稀釋、長約換約、燃料成本

### 6. 催化劑與資金流追蹤
- MSCI 成分股納入/調整
- 台灣 50 成分股異動
- 外資法人研究報告的估值框架轉變
- QE 資金環境對估值倍數的影響

## 產業適用範圍

| 產業 | 景氣領先指標 | 獲利爆發特徵 |
|------|-------------|-------------|
| 航運（貨櫃） | SCFI/BDI 指數 | 運價飆升、缺櫃塞港 |
| 記憶體（DRAM/NAND） | 合約價/現貨價、庫存天數 | 供給緊縮、價格翻倍 |
| AI 供應鏈 | GPU 出貨量、CSP 資本支出 | 訂單能見度拉長、ASP 提升 |
| 面板 | 面板報價、稼動率 | 報價止跌回升、產能利用率回溫 |
| 被動元件 | MLCC 報價、庫存水位 | 缺貨漲價、交期拉長 |
| 鋼鐵/原物料 | 鋼價指數、鐵礦砂報價 | 基建需求爆發、供給受限 |

## 設計原則

1. **數據驅動**：所有估值判斷必須有歷史回測數據支撐，拒絕主觀臆測
2. **跨產業通用**：核心框架抽象化，透過產業參數配置即可套用不同產業
3. **動態更新**：隨最新數據即時調整估值，而非靜態報告
4. **保守偏誤**：預設採用悲觀情境，避免過度樂觀的預測
5. **透明可追溯**：每個目標價計算都可回溯至具體的數據源和回測依據
